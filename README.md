# Badminton Tracker Releases

This repository hosts IPA releases and the AltStore source for the Badminton Tracker iOS app.

## AltStore Source

Add the following URL in AltStore → Browse → Sources → +:

```
https://raw.githubusercontent.com/laverty660/badminton-tracker-release/main/altstore-source.json
```

Releases are built automatically via Codemagic on every push to the main app repository.
